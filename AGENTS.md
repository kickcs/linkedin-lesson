# Working on this repo

The product is the skill in `skills/linkedin-lesson/`; everything else supports it. Users install
the `skills/` folders, so a file the skill needs at run time lives inside its folder and is reached
from `SKILL.md` by a relative path (`$S`, `$R` in the skill).

- `SKILL.md` holds the steps; `references/lesson-card.md`, `recipe/frame.md`, `recipe/looks.md`
  and the chosen look's `look.md` are read on demand. Change a rule in one place and point to it from
  the others: `frame.md` holds what every look keeps (frame, pace, loop, render, budget), `look.md`
  what is the look's own.
- `recipe/bin/` holds what the skill runs: the checks `gifcheck`, `postcheck`, `pace` (with its page
  `pace.html`), `gifpack`, the key frame `preview`, the post's bold letters `bold` and the kit
  installer `kit.mjs`; `chrome.mjs` and `serve.mjs` are their helpers.
  The tests import the logic from these files.
- Each look lives in `recipe/looks/<id>/`: `look.md`, `look.json` (name, layouts with their
  skeleton's DUR, the preview's minimum font sizes, the conclusion's lines, whether it takes a theme), `kit/` and `layouts/`.
  `kit/` and `layouts/` are copied into each lesson project, so they cannot import anything outside
  the kit. The first look in `recipe/looks.md` is the default (`DEFAULT_LOOK` in `kit.mjs`).
- A new look is a new folder: its engine reports the steps of its pace function to
  `window.LessonPace.calls` and its conclusion as `{text, at, node}` to `window.LessonPace.conclusion`
  (`pace.html` reads them), its `stage` keeps the full-frame repaint rect (`frame.md`, Known Gaps),
  its `kit/preview.html` prints `{fontsOk, title, sub, end}` for
  `preview.mjs`, its skeletons pass `pace.mjs`, `check` and the seam. Add it to `recipe/looks.md` with
  a sample frame in `examples/`, give it tests and a `tools/smoke-render.sh` run.
- A brand theme (`recipe/looks/board/theme.md`) is Board's only: it changes the palette keys of
  `Sketch.C`, the three font roles and the roughness; a new color in that engine needs a key in `C`,
  or themes cannot reach it.
- Every look's `kit/icons.js` is generated by `python3 tools/icons.py <lucide-static version>
  <name>…`, which rewrites the whole file in every look: pass the names already in it too.
- `skills/brand-profile`, `skills/voice-builder`, `skills/hook-writer` are vendored from upstream:
  keep them byte-identical and record a new upstream commit in `THIRD_PARTY.md` when updating.
- GSAP stays out of git; `recipe/bin/kit.mjs` fetches the pinned version.

When a rule changes, change its check too: the length, paragraph, hashtag and bold limits in
`postcheck.mjs`, the size, frame, loop and duration limits in `gifcheck.mjs`, the reading pace and
DUR = FADE + 0.7 in `pace.mjs` and in every look's engine, the minimum font sizes and skeleton DUR in
each `look.json`, and the numbers quoted in `SKILL.md` must agree.

Run `npm test` after any change to `recipe/` (it needs Chrome; set `CHROME` if it is not found) and
`npm run smoke` after a change to layouts, the kit or the HyperFrames pin. Everything in the repo is
English.
